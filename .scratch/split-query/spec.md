# Split-Query 规格

无服务器书签搜索 PWA：部署在 GitHub Pages、iOS 上可离线使用的 PWA。读取用户自己的文本文件（按空行切成条目），用多行搜索语法检索，链接交给系统浏览器打开。

## 领域概念

见根目录 `GLOSSARY.md`（条目 / 关键词行 / 首词 / 其他行 / 文件 / 导入）。

## 数据与生命周期

- 单文件，UTF-8 文本。
- 运行时从 iOS「文件」App 选择导入（含 iCloud 中的文件），解析后存入 IndexedDB。
- **文件是唯一真源**：重新导入时以文件为准整体替换；导入后显示条目数。
- v1 为只读 + 搜索，不做增删改。
- 离线 PWA：一次联网安装后全部本地可用；条目数据都存在本机。

## 查询语法

搜索框 = 多行可编辑文本；每个条件单元自包含（字段 + 模式 + 词）。

| 输入 | 语义 |
| --- | --- |
| `词` | 全文包含词（默认） |
| `k:词` | 关键词行包含词 |
| `k^:词` / `k$:词` / `k^$:词` | 关键词行 以词开头 / 以词结尾 / 精确等于 |
| `h:词` | 首词包含词 |
| `h^:词` / `h$:词` / `h^$:词` | 首词 以词开头 / 以词结尾 / 精确等于 |
| `!…`（`!react`、`!k:react`） | 对任意条件取反（排除） |

规则：
- 同行内空格分隔的多个条件 = **AND**；不同行之间 = **OR**。
- 词匹配为子串包含，拉丁词大小写不敏感；无短语算子。
- 算子大小写不敏感；冒号半角 `:` 与全角 `：` 等价；`!` 须紧跟算子或词（`!k:react`、`!react`）。
- 空查询 = 显示全部条目。
- 结果按导入文件顺序。

## 快捷输入

- 自动补全：候选 = 全部条目关键词行出现过的词（去重、按出现次数排序），点选插入当前行（加入 AND）。
- 工具按钮插入 / 取反各算子（`k:`、`h:`、`h^:` 等，`!` 取反），一键完整写入搜索框；行级“仅关键词行”按钮把该行每个词改写为 `k:` / `!k:`。
- 最近搜索：点按**粘贴到搜索框**再编辑，不直接重跑。
- 搜索框文字永远可手改。

## 展示

- 命中条目整体完整显示（所有行）。
- 条目内 URL 行可点击，在系统浏览器打开（不开应用内嵌网页，保留离线上下文）。

## 技术栈与部署

- 语言/构建：Vanilla TypeScript + Vite，纯静态产物。
- 存储：IndexedDB 原生 API + 薄封装。
- PWA：manifest + service worker（cache-first 缓存 app shell）；iOS standalone 元标签。
- 部署：GitHub Actions，push → `npm run build` → 部署 gh-pages。

## 已决默认

- 排除统一用 `!`＋条件一体（`!k:react`、`!react`），无符号冲突。
- 应用名暂用 split-query，图标 / 名称后续可自定义。
