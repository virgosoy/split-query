# Split-Query 规格

## Problem Statement

用户维护一个按空行切分的文本书签文件：每条目第一行为空格分隔的「关键词行」，其余「其他行」多为 URL、有时为说明文字（条目甚至只有 1~2 行）。用户希望有一款**无服务器、离线可用**的 PWA，在 iPhone 上按一套自定义搜索语法快速检索这些条目，并把链接交给系统浏览器打开。

## Solution

一个部署在 GitHub Pages 的离线 PWA（Vanilla TypeScript + Vite，无运行时框架）：

- **数据**：运行时从 iOS「文件」App（含 iCloud）导入用户的 UTF-8 文本文件；解析后存 IndexedDB；**文件是唯一真源**，重新导入整体替换（见 ADR-0001）。
- **查询**：多行编辑搜索框 — 同行空格＝**AND**、行间＝**OR**；每个条件单元自包含「字段＋模式＋词」。
- **快捷输入**：关键词行词库自动补全、算子按钮插入/取反、最近搜索粘贴回编辑框。
- **展示**：命中条目整体完整显示；URL 行点击在系统浏览器打开；结果保持导入文件顺序（不做相关度排序）。

## User Stories

1. 用户想在 iPhone 上直接选择自己的文本文件导入，以便离线查看全部条目。
2. 用户想导入后立即看到解析出的条目列表（整条目完整显示），以便确认导入正确。
3. 用户想点条目里的链接在系统浏览器打开，以便跳转到对应网页。
4. 用户在搜索框输入多个词（同行）按 AND 检索，以便只看到同时命中的条目。
5. 用户在不同行输入不同词按 OR 检索，以便一个查询覆盖多个主题。
6. 用户想让某一行只在关键词行里匹配（`k:`），以便按关键词而非链接文本检索。
7. 用户想按首词精确/开头/结尾匹配（`h:`/`h^:`/`h$:`/`h^$:`），以便定位类目/组名条目。
8. 用户想排除含某词的条目（`!:词`），以便过滤不想要的主题。
9. 用户希望算子大小写、半全角冒号都能识别，以便用中文键盘也不易打错。
10. 用户想输入时看到从关键词行汇总的候选词点选补全，以便减少打字。
11. 用户想用按钮插入/修改各算子前缀，以便不手动打符号。
12. 用户想看最近搜索并能粘贴回编辑框再调整，以便复用查询。
13. 用户想空查询显示全部条目，以便总览。
14. 用户想结果保持导入文件顺序，以便位置可预期。
15. 用户想重新导入时整体替换并看到条目数，以便更新内容。
16. 用户想刷新页面后数据仍在，以便离线使用。
17. 用户想把应用装到主屏离线使用，以便不联网也能检索。

## Implementation Decisions

- **架构**：无服务器纯静态 PWA；数据本地优先、运行时导入（ADR-0001）；应用不内嵌网页，链接一律交系统浏览器。
- **数据流**：文件（运行时导入）→ 解析为条目（parse seam）→（可选：查询谓词过滤，entry seam）→ 渲染为条目卡片。
- **测试 seam（两条，均为纯函数，v1 的唯一自动化测试边界）**：
  - **parse seam**：`文本 → 条目[]`。捕获空行切分、关键词行/首词/其他行划分、URL 识别、空白边界。
  - **query seam**：`搜索文本 → (条目)=>boolean`。捕获全部语法矩阵、大小写与半全角冒号归一、文件顺序保持（谓词不改变顺序）。
- UI 与 IndexedDB 为薄胶水，v1 不设自动化 seam（本地起 Vite 人工验证）。
- **存储**：IndexedDB 单集合；每次导入整体替换。
- **快捷输入词库**：全部条目关键词行出现过的词，去重、按出现次数降序。
- **排序**：结果始终保持导入文件顺序。
- **命名**：无关词典术语遵循 `GLOSSARY.md`。

## Testing Decisions

- 测试只经两条公开 seam（parse / query），不触碰内部实现；断言值来自**独立来源**（已知好值、规格语法矩阵字面量），避免与实现同算式。
- **parse seam**：已知文本 → 精确的条目结构断言。
- **query seam**：一张**语法矩阵表**驱动的参数化用例：对每条算子/组合给定「查询 + 命中/不命中条目」。
- 不使用 fake-indexeddb / jsdom（薄胶水人工验）。
- 运行器 vitest；本地全量通过后再进入下一票。

## Out of Scope

- v1 不做条目增删改（只读 + 搜索）。
- 不做多文件/文件夹管理（单文件）。
- 不做相关度排序、短语（`"…"`）算子。
- 不做应用内嵌浏览器；不做账号/同步/服务端。

## Further Notes

- **查询语法（完整）**：

| 输入 | 语义 |
| --- | --- |
| `词` | 全文包含词（默认） |
| `k:词` | 关键词行包含词 |
| `k^:词` / `k$:词` / `k^$:词` | 关键词行 开头 / 结尾 / 精确 |
| `h:词` | 首词包含词 |
| `h^:词` / `h$:词` / `h^$:词` | 首词 开头 / 结尾 / 精确 |
| `!…`（`!react`、`!k:react`） | 对任意条件取反 |

- 规则：行内空格=AND、行间=OR；子串匹配、拉丁词大小写不敏感；算子大小写不敏感、半角 `:` 与全角 `：` 等价；`!` 须紧接算子或词。
- 术语见根目录 `GLOSSARY.md`；架构决定见 `docs/adr/0001`。
